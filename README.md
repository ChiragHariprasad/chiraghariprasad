## Selected Systems

### V.E.C.T.O.R.

**Real-Time Fraud Detection**

A streaming fraud detection architecture combining behavioral profiling, clustering and anomaly detection to generate transaction-level risk scores.

**Core:** Isolation Forest · HDBSCAN · XGBoost · Streaming Architecture · Behavioral Clustering

**Patent:** Issued, 2025

---

### DEEP

**DNA Environmental Exploration Pipeline**

An open-set eDNA taxonomy system designed to identify known organisms while explicitly detecting potentially novel sequences rather than forcing every input into an existing class.

**Core:** Sequence Embeddings · CNN · Similarity Search · Novelty Detection · HTRP · Cloud Inference

---

### APE

**Adaptive Pedagogy Engine**

A theory-grounded recommendation system that maps student feedback and learning characteristics to pedagogical strategies using an explicit pedagogy ontology and evidence-fusion framework.

**Core:** NLP · Knowledge Representation · Recommendation Systems · Ontologies · LLMs

---

### O.R.I.O.N.

**Retail Demand & Inventory Intelligence**

An AI-driven retail intelligence system connecting household consumption signals to inventory depletion, replenishment behavior and demand forecasting.

**Core:** Forecasting · Computer Vision · NLP · Clustering · Anomaly Detection

**Patent:** Issued, 2026

---

### GENESIS

**Generative Urban Layout Planning**

A rule-aware generative system for automated urban layout generation with building-code constraints and simulation-based evaluation.

**Core:** Generative Systems · Spatial Computing · Optimization · Simulation · Constraint Reasoning

**Patent:** Issued, 2026
